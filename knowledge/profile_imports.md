# LinkedIn and GitHub analysis

Atelier can analyze a **public GitHub profile** and **LinkedIn text you paste**. It does not log in to LinkedIn, scrape behind a login, or invent jobs.

## GitHub

- Use a username or `https://github.com/username`.
- Public bio, languages, and non-fork repositories become suggested skills and projects.
- Repositories are **projects**, not employment, unless the user later confirms a role.

## LinkedIn

- LinkedIn blocks automated scraping. Paste About + Experience yourself.
- Extracted companies and titles are suggestions. They are added to the career profile only after you click apply.

## Fact protection

Never treat imported text as a reason to fabricate metrics, employers, or degrees that are not in the source or the saved profile.
