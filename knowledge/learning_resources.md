# Learning resources by skill

Python: official tutorial, then build a small API or data script every week.
SQL: window functions and joins on a public dataset until they feel boring.
Git: real pull requests, not only local commits.
Docker: containerize one of your own apps.
Machine learning: a baseline model, then one genuine improvement with an evaluation writeup.
LangChain / LangGraph: a retrieval chatbot over your own notes, with evaluation of groundedness.
System design: draw training vs serving for a project you already built.

Prefer one project that an interviewer can ask about over ten unfinished tutorials.
