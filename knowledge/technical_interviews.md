# Technical interview practice

Technical interviews test correctness, conceptual understanding, reasoning, and whether you have used the idea in practice.

For AI / ML roles, expect questions on training vs inference, evaluation metrics, leakage, retrieval-augmented generation, embeddings, and how you would ship a model behind an API.

For software roles, expect data structures, APIs, debugging, and system-design sketches.

Good answers: restate the problem, state assumptions, outline, then drill in. Name tradeoffs. If you do not know, say what you would look up and why.

This product coaches performance. It is not a personality or psychological assessment.
